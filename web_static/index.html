→

视觉直答（强参考）
→
🧠 Qwen2-7B-Instruct文本推理引擎
推理时拓展搜索

设计思想：视觉模型负责「看」——生成聚焦问题的英文视觉描述并直接看图作答；文本推理模型负责「想」——在视觉描述上进行推理时拓展。视觉答案作为强参考贯穿推理循环，与文本候选共同参与评分与聚合，实现视觉信号与语言推理的互补。

四模块协同推理流水线（Modular）

📌 模块 1 · 问题分解器主问题 → 3 个可验证子问题
→
💡 模块 2 · 思维生成器每子问题 → 3 条候选路径
→
⚖️ 模块 3 · 状态评估器按正确性一致性评分 0.1~1.0
→
🧩 模块 4 · 聚合器视觉答案 + 子答案 → 最终答案

视觉答案注入：每个子问题均由 LLaVA 直接看图作答并注入候选生成环节；主问题的视觉答案在聚合阶段作为最高优先级参考——视觉观察与语言推理互为校验。

五种推理策略

⚡ Standard（单次直答）

视觉描述 + 单次文本生成，无推理拓展。作为全流程的基线方法。

💭 CoT（链式思维）

Let's think step by step 线性推理链。一步出错则整条链失败，缺乏回溯与纠错。

🌳 ToT（思维树）

生成多条候选推理路径 → 逐条评分 → 选取最优，实现宽度优先的树形搜索空间探索。

🕸️ GoT（思维图）

候选路径构成图结构，评分环节允许跨路径的信息参照与融合，探索能力更强。

🧩 Modular（四模块协同）

分解 → 生成 → 评分 → 聚合四模块流水线，视觉答案贯穿全程，推理过程完全可追溯。

评测口径（三层流水线）

① 答案提取（extract_final_answer）——从推理链文本中定位最终答案；② 规范化（canonicalize）——同义词映射（cupboard→cabinet 等）、数字词、单复数归一；③ 等价判断（answers_equivalent）——精确匹配 → 软匹配（标准答案词集合 ⊆ 预测词集合）→ 修饰词剥离（light blue ≈ blue）。
