## 3. 核心推理能力落地（对应大纲第5章）

### 3.1 统一感知+文本推理封装
- 文件：`tot_got_integration.py`
- 做了什么：
  1. 封装 `VisionToTextReasoner`
  2. 加载 LLaVA（视觉描述生成）
  3. 加载 Qwen（文本推理）
  4. 暴露 `get_visual_description()` 与 `get_llm_caller()`
- 结果：
  - 后续 Standard/CoT/ToT/GoT/Modular 全部复用这套能力。

### 3.2 四模块实现（Modular 核心）
- 文件：`reasoning_modules.py`
- 四个模块：
  1. `QuestionDecomposer`：主问题拆子问题
  2. `ThoughtGenerator`：每个子问题生成多候选 `{thought, answer}`
  3. `StateEvaluator`：候选评分（0.1~1.0）
  4. `SearchController`：分解→生成→评估→选择→聚合
- 关键增强：
  - `_safe_json_extract` 格式容错
  - 解析失败回退策略
  - `trace` 全量记录用于可解释性与可视化

## 4. 五类方法实验脚本建设

你把五种方法都做成了独立脚本（统一输入输出接口）：

1. `run_standard_on_gqa.py`  
2. `run_cot_on_gqa.py`

4. `run_got_on_gqa.py`  
5. `run_modular_reasoning_on_gqa.py`

### 4.1 每个脚本都做了什么
- 读取 `--input_dir` 的问题文件（优先 `gqa_clean_test.jsonl`）
- 找图像路径、加载模型、逐样本推理
- 输出统一 JSON（`question/gt/pred/correct/status`）
- 支持 `--complex_only` 与 `--max_samples`

### 4.2 典型运行命令
```bash
cd /root/autodl-tmp/vision_qa_platform

python run_standard_on_gqa.py --input_dir /root/autodl-tmp/vision_qa_platform/data/processed_gqa --max_samples 1000 --complex_only --output_file /root/autodl-tmp/vision_qa_platform/results/standard_results_complex1000.json
python run_cot_on_gqa.py      --input_dir /root/autodl-tmp/vision_qa_platform/data/processed_gqa --max_samples 1000 --complex_only --output_file /root/autodl-tmp/vision_qa_platform/results/cot_results_complex1000.json
python run_tot_on_gqa.py      --input_dir /root/autodl-tmp/vision_qa_platform/data/processed_gqa --max_samples 1000 --complex_only --output_file /root/autodl-tmp/vision_qa_platform/results/tot_results_complex1000.json
python run_got_on_gqa.py      --input_dir /root/autodl-tmp/vision_qa_platform/data/processed_gqa --max_samples 1000 --complex_only --output_file /root/autodl-tmp/vision_qa_platform/results/got_results_complex1000.json
```
